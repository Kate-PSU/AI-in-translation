# AI in Translation — интерактивный тренажёр

Интерактивная самопроверка по темам CAT, MT, NMT, TM, NLP и LLM.

## Содержание

- расшифровка аббревиатур;
- различение CAT и MT;
- сопоставление понятий;
- мини-кейсы;
- итоговая самопроверка с пояснением каждого ответа.

После включения GitHub Pages тренажёр будет доступен по адресу:

https://kate-psu.github.io/AI-in-translation/
